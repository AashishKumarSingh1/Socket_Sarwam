# Socket Sarwam - Real-Time Chat Application

## Overview
Socket Sarwam is a real-time chat application that enables seamless communication between users. Built using Socket.io, it allows users to send and receive messages instantly while also tracking the number of online users. This web application serves as a companion chat platform for the Sarwam community, providing an interactive and efficient way for users to stay connected.

## Features

- **Real-Time Messaging** : Send and receive messages instantly using WebSockets.
- **Online User Tracking** : Displays the number of active users in real time.
- **Scalable Backend** : Powered by Node.js and Socket.io for high performance.
- **Efficient Data Handling** : Ensures smooth communication without delays.
- **Community Chat Support** : Acts as a helper app for the Sarwam community platform.

## Installation and Setup

### Prerequisites
Ensure you have the following installed:
- **Node.js**
- **npm (Node Package Manager)**

 ### Steps
  #### 1.Clone the Repository
  ```bash
  git clone https://github.com/AashishKumarSingh1/Socket_Sarwam.git
```

#### 2.Install Dependencies
```bash
npm install
```

#### 3.Run the Application
```bash
node server.cjs
```
